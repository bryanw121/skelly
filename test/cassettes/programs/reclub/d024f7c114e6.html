📝 Tournament & Match Rules
- 18 Pairs with 3 Pool/Group (ABC)
- Each pairs will play min. 5 match
- Top 2 from each pool (6 team) + Top 2 of 3rd rank from each pool (2 team) will advance to QF (8 pairs)
- QF winners (8 pairs) will advance to SF
- Semifinal (4 pairs)
- Final Match

🎬Scoring
- Tennis Score (15-30-40-GP)
- Group Stage/ Pool Stage = Race to 3
- Quarter, Semi Final & Final = Race to 4
- No Deuce, All Golden Point (No Tie Break)
- Winners set by: Win - Loss Points

Tie priority (in order) by
1. H2H Win
2. Total Score
3. Score Diff

Playoff (Quarter Final) 3 Pool

TOP BRACKET
- Pool A1 vs 3rd from B/C (Jika tim B lolos, maka tim C akan bermain di Bottom Bracket melawan B1)
- Pool B2 vs C2

BOTTOM BRACKET
- Pool B1 vs 3rd from A/C (Jika tim A lolos, maka tim C akan bermain di Top Bracket melawan A1)
- Pool C1 vs A2
